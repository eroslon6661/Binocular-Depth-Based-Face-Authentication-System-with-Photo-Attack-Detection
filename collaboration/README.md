# 大模型协作记录附件

Word附件采用项目组确认的第4.3节“大模型协作与纠错记录”正文。该节是项目组对协作过程的总结，不是逐轮原始聊天记录；报告中的技术结论仍须结合对应工程证据及版本核对。

|文件|内容|
|---|---|
|`ai_interaction_record.docx`|项目组确认的第4.3节正文，作为正式Word附件|
|`selected_dialogue.html`、`selected_dialogue.md`|原有11个案例的真实交互节选，保留提示、回答与否定反馈以供追溯|
|`selected_records.json`、`source_index.json`|上述真实交互节选的结构化数据与来源索引，未用报告总结替换|
|`selection_check.json`|原有真实交互节选的检查结果；不表示对新版Word或系统功能作了验证|

Word附件保留第4.3节总结正文，不改写或补造逐轮对话。完整提示、模型建议、项目组反馈及采纳或否决过程仍以独立交互记录为准。
